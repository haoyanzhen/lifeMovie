# 第一版验证记录

日期：2026-10-03

## 自动化浏览器检查

使用 Python Playwright / Chromium，测试代码在 `scripts/verify.py`。服务地址 `http://127.0.0.1:4173`。

通过项目：

- 六页完整阅读、前后翻页边界、章节跳转、左右方向键。
- 两段补充文字展开、画面显色、再次点击继续；重读后清空互动状态。
- 页码 URL 直接访问及刷新恢复。
- 来源弹窗、原文链接、Escape 关闭、关闭后焦点返回；弹窗打开时方向键不触发背景翻页。
- 声音默认关闭，开启和关闭状态正常。程序音频的审美与真实设备音量仍需人耳体验。
- 390 × 844 手机视口全部页面没有横向溢出；通过 Chromium 触摸事件验证左右轻滑逻辑。
- 320px 窄屏尾页可完整显示。
- 720px 布局宽度（对应 1440px 窗口 200% 页面缩放后的布局宽度）无横向溢出；这不是操作系统文字放大测试。
- `prefers-reduced-motion` 下关闭画面运动。
- 本地资源正常加载，无 JavaScript 运行错误或失败 HTTP 响应。

运行方式：先 `npm run dev`，再使用安装了 Playwright 与 Chromium 的 Python 执行 `python scripts/verify.py`。本次测试 Python 位于临时隔离环境 `/tmp/lifemovie-qa-venv/bin/python`，不属于项目运行依赖。

## 视觉复核

检查桌面封面、显色页、手机封面、320px 尾页、手机来源弹窗截图。修复标题不自然断行和手机页脚提示断行。三张插画已检查人物、手、主体和文字干扰；均作为非肖像性场景艺术重构使用。

截图与机器结果位于 `output/qa/`，该目录不进入发布产物。

## 构建

`npm run build` 与 JavaScript 语法检查通过。`dist/` 静态产物约 1 MB。原始 PNG 仅存于制作资产目录，发布产物只包含优化后的 WebP。

## 范围

本次为本地小样，没有外部部署。未在真实 iOS Safari、Android 浏览器或屏幕阅读器上实测；使用的是 Chromium 桌面与手机视口模拟。场景存在艺术重构和素材复用，尚非完整传记或连续视频。
