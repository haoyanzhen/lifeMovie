# 一生，又一生

设计记录 · 2026-10-03 · 第二版

## 这次修正的核心

用户指出：第一版只列举晚年的学习节点，没有人生的尺度，也没有表达时间与关系如何支撑一次重新开始。页面文字过多，阅读提示和抒情解释反而分散注意力。

这条反馈成为后续制作原则：不告诉观众慢慢看，不替观众总结感动；让画面、经历和关系自行产生情绪。

## 叙事结构

先走过前半生，再进入晚年的新起点。保留养育、相助、迁徙、孩子长大、失去、重新学习这条因果链。母亲照料孩子，长大的女儿陪母亲学字，是情感转折。前半生的事情不只用于交代背景，还在晚年的写作和绘画里重现。

最终不是用出版数量证明成功，而是让最初的红褂女孩出现在老人的画纸上。她在晚年重新拥有好奇心、讲述权和“以后”。红褂女孩的具体构图属于艺术想象，晚年画童年的自己有采访依据。

## 文字节制

- 常规页仅一个时间标签和一两句叙事。
- 删除大标题、副文案、图片题注之间的同义重复。
- 删除“慢慢读”“不必急着翻页”“把平常日子收好”等观众指导与抒情装饰。
- 删除双重页码、英文字标、章名列表、角落印章和竖排旁白。
- 资料考据、生成图说明、年龄差异集中在“来源与创作”弹窗。
- 不用展开更多文字作为主要互动奖励。

## 视觉与交互

以画面为主体，不再使用文字与图片各占一栏的介绍页布局。保留暖纸色和克制的电影感插画。一页一个主体，时间和短句位于画面下方。手机以画面优先，避免先读一屏说明才能看到人物。

只保留三处可选互动：翻开往事、让绘画显色、从晚年画作回看童年。互动不阻止继续翻页。普通翻页、键盘和触摸保持可用，末页的回转箭头重新开始。

图片预解码后再一起更新画面和文字，使用短叠化连接不同场景。快速翻页以最后一次操作为准。减少动态偏好关闭运动和叠化；声音默认关闭。

## 资产和边界

新增七张内置图像工具生成的插画，以原场景作为画风参考。新图、旧图和源 PNG 均保存在项目里。末页以旧绘画图为编辑目标，童年图为画中人物参考。所有插画都是非肖像性艺术重构，不是真实照片、住宅或手稿。

一席、新华每日电讯与澎湃采访共同支撑时间和家庭事实。原第一版设计保存在 `design-v1.md`，代码快照保存在本地 `output/v1/`。

验收应先看故事是否有前后呼应、关系是否清楚，再检查排版与交互；页数增加不等于人生尺度自然成立。
